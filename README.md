## FAQ

### Is OmniPatch safe to use on my computer?

OmniPatch is designed as a standalone utility and does not install persistent background services. However, because it modifies application binaries, it may be flagged by some anticomponent software. Always scan files and use at your own discretion.

### Which versions of the supported AI applications are compatible?

OmniPatch is regularly updated to support the latest stable desktop versions of ChatGPT, Claude, Perplexity, Microsoft Copilot, Cursor, GitHub Copilot, Devin, and JetBrains AI. Check the README for specific version numbers.

### How often is OmniPatch updated?

Updates are typically released within 48-72 hours after a major update to any of the supported AI applications, ensuring continuous compatibility and feature access.

### Does this require an internet connection?

The patcher itself runs offline. However, the patched AI applications will still require an internet connection to function, as they communicate with their respective cloud services.

### Will this affect my AI application's performance?

The patch modifies activation checks and feature gates, not the core AI processing. Application performance, speed, and quality of responses remain unchanged.

### Can I revert the changes after applying the patch?

The patcher does not create backups. To revert, you would need to uninstall and then reinstall the original versions of the AI applications.

### Is OmniPatch compatible with macOS or Linux?

No, OmniPatch is a Windows-only utility (.exe) and is designed specifically for patching Windows desktop applications.
